🍅 Panel de administración de Jujalandia

Editá el ticker de noticias y los cómics del sitio. Esto NO publica solo — descargás el archivo y lo subís a GitHub.

Cómo aplicar los cambios:
  1. Editá lo que quieras acá abajo.
  2. Apretá "Descargar" en la sección que cambiaste.
  3. Andá a tu repositorio en GitHub → carpeta content/ → abrí el archivo (ticker.json o comics.json) → ícono de lápiz ✏️ (Edit) → borrá todo → pegá el contenido del archivo descargado → "Commit changes".
  4. A los 1-2 minutos GitHub Pages actualiza el sitio solo.
  5. Para fotos de páginas de cómic: subilas primero a la carpeta uploads/ del repo ("Add file → Upload files"), y después escribí acá el nombre, ej: uploads/comic-ep1-pag1.jpg.
